## 📌 Featured Projects

### 1. AI Teacher Assistant

An AI-powered video question-answering system built using Retrieval-Augmented Generation (RAG).

**Features**
- Processes 20 Java lecture videos totaling approximately 1.9 hours.
- Extracts audio using FFmpeg and generates timestamped transcripts with Whisper.
- Divides transcripts into 372 searchable chunks.
- Uses BGE-M3 embeddings and cosine similarity to retrieve relevant content.
- Generates answers using Gemma 2 through Ollama locally.
- Returns relevant lesson numbers and timestamps.

**Evaluation**
- 97.5% top-5 lesson accuracy.
- 92.5% timestamp accuracy within 60 seconds.
- Approximately 6-second response time on local hardware.

**Technologies:** Python, Whisper, BGE-M3, Ollama, Gemma 2, FFmpeg, Scikit-learn, Joblib.
